# Simple Interest Calculator

A simple calculator to calculate simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal = The initial amount of money
- Rate = Rate of interest
- Time = Time period in years

## Example

If the principal is 1000, the rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100

## Features

- Calculates simple interest
- Accepts principal amount as input
- Accepts rate of interest as input
- Accepts time period as input
