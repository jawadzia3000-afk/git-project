# Simple Interest Calculator

A simple calculator to calculate the simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest (SI) is calculated using the following formula:

SI = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

## Example

If:

- Principal = $1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = $100

## Features

- Calculates simple interest
- Easy to use
- Takes principal, rate, and time as inputs
- Displays the calculated interest

## Purpose

This project demonstrates the basic implementation of a simple interest calculator using programming concepts and GitHub.
